## ۱. لایهٔ هدف و چرا احیاپذیر است

**S366 / XAUUSD-M30 (arm گیت‌دار):** قوی‌ترین مهارتِ خام اندازه‌گیری‌شده روی طلا در کل پروژه:

```
n = 7,185 معامله (۱۲ عضو pooled) · z = +4.94σ · lift_R = +0.0673
حکم: DEAD_NEGATIVE_ABSOLUTE — چون e_pip = lift×SL̄ = +2.24 pip < c = 3.30 pip
```

مهارت واقعی است (×۱.۶ بالای کران شانس)، پول منفی است. علت مرگ، **خروج** بود نه ورود:
براکت measured-move (`TP=m·chan_h`) سود را در سقفی قطع می‌کند که پس از کسر اسپرد طلا
زیر هزینه می‌ماند. متن Brooks خودش می‌گوید شکست «حداقل دو پای دیگر» ادامه می‌یابد —
یعنی برش سود در `1.0×chan_h` حتی با متن هم ناسازگار است.

**فرضیهٔ S552 (ابطال‌پذیر):** اگر رانشِ پس از شکست واقعی است (z=4.94 می‌گوید هست)،
حذف سقف TP و سپردن خروج به زمان (V-TIME) باید `e_pip` را بالای `c=3.3` ببرد.
**حالت ابطال:** اگر e_pip با خروج آزاد هم زیر هزینه ماند، یعنی لبه فقط «جهت‌گیری چندکندلی
کوتاه» است که در مقیاس زمانی الگو تبخیر می‌شود ⇒ فصل Stairs برای طلا برای همیشه بسته
اعلام می‌شود و این نتیجه هم با همان دقت گزارش می‌شود.

## ۲. تعریف منجمد سیگنال (عیناً از S366 — هیچ دستکاری مجاز نیست)

از `strategies/s366_stairs_channel_breakout.py` (در تاریخچهٔ git):

```
پیوت‌ها: swing high/low با بازوی k، تأییدشده در t=p+k (بدون نشت آینده)
زمینهٔ کانال: ۵ پیوت متناوب؛ شیب‌دار + همپوشان؛ خط پایین از دو L آخر،
             خط بالا موازی از H؛ chan_h = ضخامت عمودی؛
             shrink = پلهٔ آخر < پلهٔ قبلی
رویداد (گیت Brooks — همان arm A که z=4.94 داد):
    shrink=False → شکست هم‌جهت شیب   (خرسی: close<lower ⇒ SHORT؛ گاوی: close>upper ⇒ LONG)
    shrink=True  → شکست برگشتی        (خرسی: close>upper ⇒ LONG؛ گاوی: close<lower ⇒ SHORT)
فقط نخستین شکست هر زمینه (seg). ورود: کندل بعد (قرارداد موتور).
قید ریزساختاری S366 (sl,tp ≥ cost و tp ≥ 2·cost) دیگر موضوعیت ندارد چون براکت
measured-move حذف می‌شود؛ به‌جایش براکت q98 خودش بسیار بزرگ‌تر از cost است (گزارش می‌شود).
warmup = min(260, max(30, n_bars//8))   — عیناً قاعدهٔ S366
```

**تغییر یگانه — پیوند خروج (و بس):**

با حذف براکت measured-move، محورهای `m,s` از تعریف **حذف** می‌شوند (آن‌ها فقط خروج بودند).
سیگنال به **اجتماع سه جریان ورودی `k∈{2,3,5}`** فرو می‌کاهد:

```
سیگنال S552 = union(k=2, k=3, k=5) اولین-شکست‌ها؛ چند k روی یک کندل = یک سیگنال
              (dedupe؛ جهت از زمینهٔ همان k با کوچک‌ترین k می‌آید — قاعدهٔ قطعی)؛
              همپوشانی معاملات را موتور با allow_overlap=False حذف می‌کند.
⇒ هیچ عضوی انتخاب نمی‌شود، آمارهٔ حاکم trade-pooled است (قانون FAMILY_MEAN_OPTIMISM).
```

**خروج V-TIME (دستور عیناً از S560، بدون جاروب):**

```
max_hold (mh): قاعدهٔ خودِ S366 — 2 × میانهٔ مدت کانال‌ها (L1→شکست) در همان کارت،
               سقف 400 بار. از هندسهٔ الگوست، نه از نتیجهٔ معاملات.
براکت فاجعه:  SL = TP = q98( MFE ∪ MAE )  در افق mh (هر دو نامنفی‌اند)،
               فقط از سیگنال‌های پارهٔ اکتشاف (۶۰٪ نخست به‌وقت ورود).
               متقارن ⇒ سپر ضدتقلب TP<SL خودکار برقرار.
```

هیچ پارامتر جدیدی وجود ندارد: k همان سه مقدار پیش‌ثبت S366، mh از قاعدهٔ ثبت‌شدهٔ S366،
q98 و «فقط پارهٔ اکتشاف» عیناً دستور S560. **جاروب هیچ‌چیز مجاز نیست.**
