## ۳. تعریف منجمد

با `Lmin[i] = rolling_min(low, 55)` روی بازهٔ `[i−55, i−1]` (علّی؛ LOOK=55 منجمد پیشینی — فیبوناچی، بدون جستجو) و `τ = c×ATR100[i]`:

**رویداد (LONG-only):**
- `low[i] ≥ Lmin[i]` (نگهداشت — بدون نفوذ)
- `low[i] ≤ Lmin[i] + τ` (لمس ناحیهٔ حمایت)
- `close[i] > Lmin[i] + τ` (بسته‌شدن قاطع بالای ناحیه — رد)
- **گیت درفت (منجمد S950):** `close[i−1] > close[i−90]`
- ورود: open کندل i+1 + slip

**خانوادهٔ جستجو (24 trial):**
- TF ∈ {H1, H2, H4} · c ∈ {0.1, 0.2}
- k_sl ∈ {1.5, 2}×ATR100 · RR ∈ {1, 1.5} — بودجه TP≥SL ✓
- max_hold: H1=96, H2=64, H4=48 (منجمد، همان S626)
- **n_trials = 3×2×2×2 = 24**

**هزینه:** spread=3.3 + 2×slip=1.0 pip · pip=0.10 · شبیه‌ساز رسمی `engine/scalp_engine.simulate_trades`

**null اندازه‌گیری‌شده (قوانین S346+S612):** ورودهای بی‌قید از بارهای معتبرِ **drift>0** با همان هندسهٔ منجمد per-(k_sl,rr) — دقیقاً همان null اثبات‌شدهٔ S626.
