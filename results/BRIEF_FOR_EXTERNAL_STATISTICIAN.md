## ۱. پروژه چیست

یک تیمِ تحقیقاتی روی **الگویابی در دادهٔ کلانِ بازارهای مالی** کار می‌کند. دارایی‌های
هدف: **XAUUSD** و **EURUSD**. هدفِ عملیاتی: یافتنِ «لایه»هایی (قواعدِ معاملاتیِ
مستقل و بک‌تست‌پذیر) که یک معیارِ آماریِ سخت به نامِ **RQS2** را پاس کنند، و اتصالِ
لایه‌های پذیرفته‌شده به یک سایتِ تصمیم‌یارِ ماژولار.

**مقیاسِ کارِ انجام‌شده تا امروز:**

| سنجه | مقدار |
|---|---|
| استراتژی‌های کشف و آزموده‌شده (مرحلهٔ ۱) | ~۲۰۰ |
| فایلِ گزارشِ استراتژی در `results/` | ۲۵۸ فایلِ MD |
| لایه‌هایی که با معیارِ **RQS2** داوری شده‌اند | **۸ لایهٔ متمایز** |
| جفت‌های (لایه × کارت) داوری‌شده | ۴۹ |
| حکم‌های مجزای صادرشده | ۲۶۳ |
| توزیعِ آن ۲۶۳ حکم | ۲۲۷ REJECT · ۱۸ POWER-LIMITED · ۱۲ INCOMPLETE · ۳ ACCEPT · ۳ بی‌حکم |
| لایه‌های وصل‌شده به سایت (با نمرهٔ منسوخِ RQS+ یا RQS2) | ~۲۵ لایه روی ۹ کارت |
| بانکِ اندیکاتور | **۴۰۱ اندیکاتور** پیاده‌سازی‌شده |
| منابعِ خامِ تلگرام (EA/اندیکاتور/کتاب) | ۳۴۹ ورودی؛ **۷ موردش** تا امروز بررسی شده |

⚠️ **نکتهٔ حاکمیتیِ مهم:** «۲۰۰ استراتژی» و «۲۵ لایهٔ روی سایت» با معیارِ **قدیمِ

اکثرِ سایت **اعتبارسنجیِ به‌روز ندارد** — این یکی از مشکلاتِ بازِ ما است (§۷).

## ۲. معیارِ RQS2 v2.4 — کامل و دقیق

پذیرش = **پاس‌کردنِ هر ۱۱ دروازه**. کفِ نمره‌ای (۸۰) عمداً **بازنشسته** شد؛ نمره
فقط رتبه می‌دهد (`A≥80 · B≥65 · C≥50 · D<50`). دلیلِ بازنشستگی: یک جمعِ وزنی بنا به
ساختِ خود **جبران‌پذیر** است، ولی دروازه‌ها عمداً **جبران‌ناپذیر** طراحی شده‌اند؛
آستانه‌گذاری روی نمره، منطقِ بده‌بستان را از درِ پشتی برمی‌گرداند.

### ۲.۱ جدولِ ۱۱ دروازه

| دروازه | نام | شرطِ پاس |
|---|---|---|
| **H0** | کفایتِ نمونه و استقلال | `n ≥ 30`؛ بیشینهٔ هم‌زمانیِ معاملات `= 1`؛ اگر دوسویه، هر سمت `n ≥ 15` |
| **H1** | کیفیتِ خام | `WR ≥ 60%` **و** `PF ≥ 1.3` |
| **H2** | لبهٔ هندسیِ هزینه‌دار (ضدِ تقلب) | `tp_pip` صریح؛ `WR − (SL+c)/(SL+TP) ≥ 3pp`؛ `RR = TP/SL ≥ 0.5`؛ `exp > 0` |
| **H3** | ⭐ مهارت نسبت به مدلِ صفر | `lift ≥ 4pp` **و** `p_perm ≤ 0.001` (≡ `z ≥ 3.09σ`) **و** `perm_k ≥ 500`؛ اگر `perm_k < 500` ⇒ `UNKNOWN` |
| **H4** | مهارتِ هر سمت | برای هر سمتِ فعال: `lift_side ≥ 2pp` و `exp_side > 0` |
| **H5** | بقا در آزمونِ چندگانه | `p_adj = min(1, p × n_trials) < 0.05` |
| **H6** | پایداریِ تقویمی | ≥۳ از ۴ بازهٔ تقویمی مثبت؛ **هر دو نیمه** مثبت؛ بدترین بازه ≤ ۲۵٪ نتِ کل؛ ≥۳ بازه دارای معامله |
| **H7** | خارج از نمونه (holdout) | `n ≥ 15` · `WR ≥ 57%` · `PF ≥ 1.2` |
| **H8** | ریسکِ دنباله و بازیافت | `maxDD ≤ 8%` · `MCL ≤ 8` · `net/|DD| ≥ 3` |
| **H9** | مقاومتِ هزینه | `exp > 0.5×spread` **و** `exp@2×spread > 0` |
| **H10** | ⭐ مقاومتِ رژیمی (خلافِ جریان) | `exp_counter > 0` **و** `WR_counter ≥ breakeven_cost`؛ اگر `n_counter < 20` ⇒ آزمونِ جانشین |

### ۲.۲ سه نکتهٔ فنیِ مهم دربارهٔ معیار

**الف) H3 و مدلِ صفر.** آزمونِ جای‌گشت **ترتیبِ زمانی را به‌هم می‌ریزد ولی رانشِ کلِ
نمونه را حفظ می‌کند**. پس H3 ساختاراً نمی‌تواند بپرسد «اگر رانش نبود چه؟». به همین
دلیل H10 اضافه شد: رانشِ حاکم = علامتِ بازدهِ ۲۰۰ روزِ معاملاتیِ گذشته (causal)؛
معاملهٔ خلاف‌جریان = (long و رانش ≤ ۰) یا (short و رانش ≥ ۰).

**ب) H5 و شمارشِ چندگانگی.** سد از `E[max z]` برای `n_trials` آزمونِ مستقل ساخته
می‌شود. اعدادِ واقعیِ فعلی:

```
n_trials = 112  →  bound = 2.5702
n_trials = 117  →  bound = 2.5854
n_trials = 153  →  bound = 2.6768
```

پروژه یک **دفترِ چندگانگیِ تجمعی** نگه می‌دارد که فقط بالا می‌رود. الان روی **۱۵۳**
است. **این عدد هرگز صفر نمی‌شود** و هر نشستِ جدید آن را بالاتر می‌برد.

**ج) حکمِ سه‌حالته.** `ACCEPT` / `REJECT` / `INCOMPLETE`. سومی برای وقتی است که
داوری **ممکن نیست** (مثلاً `NaN` در سود، یا `perm_k<500`) — و عمداً از `REJECT`
تفکیک شده، چون «ادعا نشده ≠ رد شده».

### ۲.۳ هیستوگرامِ شکست روی ۲۵۰ رکوردِ مرده

```
H3 : 248     H5 : 233     H7 : 227     H10 : 215     H8 : 196
H6 : 167     H1 : 175     H4 : 166     H9 : 122     H2 : 109     H0 : 47
```

**خوانشِ خودمان:** `H3` بیشترین شکست را دارد ولی گلوگاه نیست چون تقریباً همیشه
هم‌زمان با `H5`/`H7` می‌افتد. **گلوگاهِ واقعی `H5` (چندگانگی) و `H7` (خارج‌ازنمونه)
است — و هر دو در اصلِ خود مسئلهٔ «کفایتِ نمونه»اند.** (پرسشِ Q1 در §۸ درست همین‌جاست.)

## ۳. مدلِ هزینه و مشخصاتِ داده

### ۳.۱ مشخصاتِ حسابِ دمو (ملاکِ همهٔ بک‌تست‌ها)

```
CONTRACT_SIZE = 100        (۱ لات = ۱۰۰ اونس؛ حرکتِ ۱.۰۰$ = ۱۰۰$ به‌ازای هر لات)
اسپردِ واقعی XAUUSD = 0.33 $/oz  (~۳.۳ pip = ۳۳ point)
کمیسیونِ جداگانه   = ندارد
مارجین            = ۴۰$/لات
```

هزینهٔ رفت‌وبرگشتِ استفاده‌شده در محاسبات: **XAUUSD = 3.3 pip · EURUSD = 1.6 pip**.

### ۳.۲ داده‌های موجود

| دارایی | تایم‌فریم‌های موجود | نکته |
|---|---|---|
| **XAUUSD** | M5, M15, M30, H1, H4, D1, W1 | ⚠️ **M1 موجود نیست** |
| **EURUSD** | M1, M5, M15, M30, H1, H4, D1, W1 | کامل |
| DXY | M5, M15, M30, H1, H4, D1, W1 | فقط کمکی |

اندازهٔ نمونه: کارت‌های ریز ۱۵۰٬۰۰۰ تا ۲۰۰٬۰۰۰ کندل؛ `W1` فقط ~۴۰KB (چند صد کندل)
⇒ کارت‌های `D1`/`W1` معمولاً **نمونهٔ کافی برای هیچ لایه‌ای تولید نمی‌کنند**.

⚠️ یک قیدِ اندازه‌گیری‌شده: `EURUSD-M1` تاریخش **۱۹۷ روز** است، کوتاه‌تر از افقِ
۲۸۰روزهٔ `H10` ⇒ حکمش همیشه `INCOMPLETE` می‌شود، نه `ACCEPT`.
