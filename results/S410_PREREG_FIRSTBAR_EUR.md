## ۲. پروتکلِ چندگانگی — مسیرِ `C`

1. **تقسیم:** `split_bar = int(0.5 × len(df))` روی EURUSD-M15 — تنظیم **فقط**
   روی نیمهٔ اول. نیمهٔ دوم تا آزمونِ نهایی **دست‌نخورده** می‌ماند.
2. **آزمونِ یک‌ضرب:** پس از انجمادِ پیکربندی، فقط **یک** اجرای رسمی
   `compute_rqs2` روی کلِ داده با `split_bar` بالا. دوبار دست‌زدن به نیمهٔ دوم = تقلب.
3. **MTF:** پیکربندیِ منجمدشده از M15، بدونِ هیچ تنظیمِ مجدد، یک‌ضرب روی
   M30 و سپس H1 داوری می‌شود (max_hold بر حسبِ **ساعت** با `bars_per_hour`
   اندازه‌گیری‌شده — ضدِ BUG-TFM). **M1 ممنوع** (تاریخچه ۱۹۷ روز < افقِ H10).
4. **حکم:** فقط خروجیِ `compute_rqs2`/`format_rqs2` v2.6. هر حکمی بود، همان
   مستند می‌شود؛ REJECT روی دروازهٔ نابخشودنی ⇒ توقف، بدونِ تنظیمِ مجدد.

## ۴. فضای فیلتر و هندسه (کامل، بسته، قابلِ شمارش)

**نگه‌داری (time-exit اصلی):** `hold_hours ∈ {1.0, 1.5}` (≡ ۴ و ۶ کندلِ M15)

**هندسهٔ حفاظتی — مقیدِ قانونِ دسترس‌پذیریِ سد** (MFE در ۶ کندل: p50=4.75،
p75=7.27، p90=11.0 pip؛ نرخِ لمسِ ۱۲pip فقط ۸.۱٪ ⇒ TPِ نزدیک تزئینی است):

```
G1: SL=12 pip، بدون TP (خروجِ زمانی)
G2: SL=18 pip، بدون TP (خروجِ زمانی)
G3: SL=12 pip، TP=12 pip (متقارن، برای سنجشِ H2 با سدِ واقعی)
```

**فیلترِ تکی (حداکثر یکی روی پایه؛ فهرست از خودِ MISSION_2):**

| # | فیلتر | تعریفِ دقیق (بدونِ ابهام) |
|---|---|---|
| F0 | هیچ | پایهٔ خالص |
| F1 | dip کوتاه | جابه‌جاییِ خالصِ ۴ کندلِ قبل < 0 (خانوادهٔ S430 — برای ممیزیِ هم‌پوشانی عمداً حاضر) |
| F2 | dip بلند | جابه‌جاییِ خالصِ ۸ کندلِ قبل < 0 |
| F3 | گپِ شبانه منفی | open(00:00) − close(23:45 دیروز) < 0 |
| F4 | جهتِ دیروز نزولی | close(دیروز) < open(دیروز) |
| F5 | RVOL پایین | رنجِ ۲۴hِ قبل < میانهٔ رنجِ ۲۴h روی نیمهٔ اول |
| F6 | رژیمِ همبستگیِ XAU-EUR | |corr غلتان ۲۰روزه| < میانه روی نیمهٔ اول (رژیمِ استقلال) |
| F7 | روزِ هفته | حذفِ بدترین روزِ اندازه‌گیری‌شده در نیمهٔ اول (۱ روز، فقط یک انتخاب) |

**ترکیبِ دوتایی:** فقط **دو فیلترِ برترِ** مرحلهٔ تکی (به معیارِ بندِ ۵) با هم،
روی همان ۲×۳ سلولِ نگه‌داری/هندسه. هیچ ترکیبِ سه‌تایی مجاز نیست.
