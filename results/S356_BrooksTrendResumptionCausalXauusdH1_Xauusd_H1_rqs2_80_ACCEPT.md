## ۱. چرا این لایه مرده بود — و چرا آن مرگ حکم نبود

### ۱.۱ مرگِ اول (واقعی): look-ahead

نسخهٔ اولیه پنجرهٔ پایانیِ روز را چنین تعریف می‌کرد:

```python
late_start = day_start + round(0.68 * len(day))     # ← طولِ کلِ روز
```

`len(day)` طولِ **کلِ** روز است. در ساعتِ ۱۰ صبح، هیچ‌کس نمی‌داند روز چند کندل
خواهد داشت. این look-ahead واقعی است و لایه به‌درستی کنار گذاشته شد.

### ۱.۲ نسخهٔ causal و مرگِ دوم (نامعتبر)

نسخهٔ causal پنجره را با **ساعتِ ثابتِ UTC** تعریف کرد (`hour ≥ 16`) — که در
لحظه معلوم است. این نسخه در دروازهٔ `H3` رد شد. اما شرطِ `H3` آن زمان این بود:

```
WR_observed  >  max(permutation draws)
```

**این آماره معیوب است**، چون `max` یک آمارهٔ **ناپایدار** است که با تعدادِ قرعه
بی‌کران رشد می‌کند. مدرکِ عددی از خودِ همین لایه:

## ۷. پورت به TypeScript — و دو انحرافِ خطرناکی که کشف شد

ماژولِ TS از قبل وجود داشت اما از **نسخهٔ non-causal** پورت شده بود.

### انحرافِ ۱: پنجرهٔ پایانی

```ts
const lateStart = ds + Math.round(cfg.lateFrom * ndlen)   // ❌
```

در پورتِ زنده `ndlen` = کندل‌های **تاکنونِ** روز شده بود. آنگاه شرطِ
`pos ≥ round(0.68 × (pos+1))` از `pos≈2` به بعد **همیشه صادق** است ⇒ پنجرهٔ
پایانی عملاً **بی‌اثر**.

### انحرافِ ۲: براکتِ شناور

```ts
const slPip = cfg.slK * (atrRef / cfg.pip)   // ❌ ATR همان روز
```

پایتونِ داوری‌شده از **medianِ سراسری** استفاده می‌کند ⇒ یک عددِ ثابت
(۵۰.۶) برای هر ۱۱۷ معامله. براکتِ متغیر یعنی برآمدهای متفاوت ⇒ WR، PF و نالِ
متفاوت. سایت هندسه‌ای را تبلیغ می‌کرد که **هیچ دروازه‌ای آن را نپذیرفته بود**.

### اثباتِ عددی: parity قبل و بعد

| | پایتون | TS **قبل** | TS **بعد** |
|---|---:|---:|---:|
| تعداد سیگنال | ۱۱۷ | **۳۰۲** | **۱۱۷** |
| اشتراک | — | ۷۳ | **۱۱۷** |
| mismatch | — | **۲۷۳** | **۰** ✅ |

توزیعِ ساعت بعد از اصلاح **سطل‌به‌سطل** یکسان شد:
`{16:47, 17:28, 18:10, 19:9, 20:8, 21:7, 22:7, 23:1}` — این قوی‌تر از تساویِ
تعداد است، چون دو مجموعهٔ هم‌اندازه می‌توانند اعضای متفاوت داشته باشند.

> **نیمهٔ ظریفِ خرابی:** ۴۴ سیگنالِ **واقعی** هم گم شده بودند. چون لایه فقط
> «اولین شکستِ هر روز» را می‌گیرد، یک شکستِ کاذبِ صبحگاهی روز را **مصرف**

> معاملهٔ اضافه می‌سازد، بلکه معاملهٔ واقعی را **نابود** می‌کند.
