## ۱. فرضیه‌ی علمی

وایلدر (1978): وقتی میانگین هموارشده‌ی حرکت جهت‌دار مثبت از منفی پیشی می‌گیرد
(+DI×−DI کراس)، توزیع حرکت‌های آتی به سمت جهت غالب کج است. در طلا که روندهای
کلان چندماهه دارد (بازار گاوی سکولار + جریان‌های پناهگاه امن)، این سنجه باید در
افق‌های درشت حامل اطلاعات تداوم باشد. fade نیز به‌عنوان عضو خانواده از پیش اعلام
می‌شود (اگر بازار کراس‌ها را می‌سوزاند، معکوسش اطلاع دارد) — کشف بعدی وجود ندارد.

## ۲. تعریف منجمد قاعده (صفر پارامتر جست‌وجوشده)

**DMI کلاسیک وایلدر با دوره‌ی متعارف P=14 (عدد کتاب — نه تیون):**
```
+DM_t = max(high_t − high_{t−1}, 0)  اگر > (low_{t−1} − low_t) وگرنه 0
−DM_t = max(low_{t−1} − low_t, 0)   اگر > (high_t − high_{t−1}) وگرنه 0
TR_t  = true range
هموارسازی وایلدر (ewm alpha=1/14) روی +DM، −DM، TR
+DI = 100×s(+DM)/s(TR) · −DI = 100×s(−DM)/s(TR)
DX  = 100×|+DI−−DI|/(+DI+−DI) · ADX = وایلدر-هموار DX (14)
```
**رویداد:** کراس `+DI` از `−DI` (بالا→LONG-candidate در follow) یا آینه؛ روی کندل
بسته‌شده‌ی t؛ ورود open کندل t+1 (موتور رسمی).

**واریانت‌ها (خانواده‌ی کامل، بسته — ۴ عضو):**
1. `plain-follow` — هر کراس، ورود هم‌جهت.
2. `plain-fade` — هر کراس، ورود خلاف جهت.
3. `gated-follow` — فقط اگر `ADX_t ≥ 20` (آستانه‌ی متعارف کتاب وایلدر — نه تیون).
4. `gated-fade` — آینه‌ی ۳.

**هندسه (وراثتی):** SL = `1.5×ATR(100)` کندل سیگنال (آرایه‌ای، علّی)، TP = `1.5×SL`
(RR=1.5، TP>SL)، `max_hold = 56` کندل (=۴×دوره‌ی ۱۴ — ساختاری، نه تیون)،
`allow_overlap=False`، اسپرد 3.3 pip، بدون کمیسیون، contract=100.
