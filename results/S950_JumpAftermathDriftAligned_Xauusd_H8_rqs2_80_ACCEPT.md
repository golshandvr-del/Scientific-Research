## ۲. فرضیهٔ علمی (چرا باید کار می‌کرد)

مدلِ Jump-Diffusion (Merton 1976): بازده = انتشارِ پیوسته + پرش‌های پواسونیِ کم‌بسامد.
کندلی که |r| آن چند برابرِ **مقیاسِ انتشارِ محلی** است، عضو جمعیتِ diffusion نیست —
حامل اطلاعات است (خبر/جریانِ سفارشِ کلان) و جذبِ کاملِ اطلاعات تدریجی است ⇒ ادامه.

**تمایز از S327 سوخته:** مقیاسِ انتشار با **Bipower Variation** (Barndorff-Nielsen &
Shephard 2004) سنجیده شد: `BV = (π/2)·mean(|r_i||r_{i-1}|)` روی پنجرهٔ ۸۹ (فیبوناچی)،
causal تا t−1. BV **جهش-مقاوم** است — خودِ پرش واردِ مقیاس نمی‌شود، پس آستانهٔ
`|r| > k·σ_BV` پس از یک پرش «کور» نمی‌شود. ATRِ ساده (ابزار S327) دقیقاً همین‌جا می‌شکند.

## ۳. قاعدهٔ نهایی (قابلِ پورتِ کلمه‌به‌کلمه)

```
σ_BV(t)  = sqrt( (π/2) · mean_{89}( |r_{i}|·|r_{i-1}| ) )   # فقط تا t−1 (causal)
جهش      = |r_t| > 2.6 · σ_BV(t)
درفت     = close[t−1] − close[t−90]                          # رژیم ۸۹ کندلی، causal
LONG سیگنال  : r_t > +2.6·σ_BV  و  درفت > 0
SHORT سیگنال : r_t < −2.6·σ_BV  و  درفت < 0
ورود: open کندلِ بعد · SL = 2.058×ATR(89) (causal، بر حسب pip) · TP = SL (RR=1)
max_hold = 34 کندلِ H8 · allow_overlap=False · warm-up = 91 کندل
```
پارامترها همگی غیرِ رُند (فیبوناچی/مشتقات): 89، 2.6، 2.058، 34. **TP=SL ⇒ قانونِ بودجه (TP≥SL) برقرار.**
میانهٔ SL≈TP ≈ **242 pip** (≈ $24.2/oz).
