# یافتهٔ روش‌شناختی: «قانونِ کیفیتِ پایه در مقیاسِ زمانی» + «سقفِ لیفتِ فیلتر»

> منشأ: نشستِ S346 (منبعِ `Adaptive ATR channel.mq5` — mladen 2018).
> این فایل یک **یافتهٔ فرا-استراتژی** است، نه یک لایه. کاربردش در **همهٔ**
> نشست‌های آیندهٔ پروژه است، مستقل از این‌که کدام منبع بررسی می‌شود.

---

## ۱. مسئله‌ای که این یافته حل می‌کند

پرسشِ همیشگیِ پروژه: «چه‌وقت یک لایه را سوخته اعلام کنیم؟»
تا پیش از این، پاسخ **کیفی** بود («هیچ ترکیبی از بهبودها نجاتش نداد»). مشکل:
فضای ترکیب‌ها بی‌نهایت است، پس این معیار عملاً هرگز ارضا نمی‌شود و ما بین
«رهاکردنِ زودهنگام» (اشتباهِ رایجِ #۳) و «حفرِ بی‌پایانِ یک چاهِ خشک» گیر می‌کنیم.

این یافته یک **معیارِ کمّی و قابلِ محاسبه** به‌دست می‌دهد.

---

## ۲. سنجهٔ ۱ — سقفِ لیفتِ فیلتر (اندازه‌گیری‌شده)

**پرسش:** انباشتِ فیلتر حداکثر چند درصد WR را می‌تواند بالا ببرد؟

**آزمون:** هندسهٔ پرظرفیتِ `XAUUSD-M15 / breakout / both / p=21 / m=1.272 / h=5`
با غربالِ **کلِ ۴۰۱ ابزارِ بانک** + انباشتِ حریصانهٔ چندفیلتری:

| مرحله | n (پس‌از‌صف) | WR | PF |
|---|---|---|---|
| پایهٔ خام | ۲۹٬۷۱۳ | ۴۷.۳۲٪ | ۰.۷۹۶ |
| پس از غربالِ ۴۰۱ ابزار + انباشت | ۲۳۸ | **۵۳.۷۸٪** | ۰.۹۵۵ |
| تفکیکِ تکرارپذیری | D: n=۱۶۷ WR=۵۳.۸۹ — H: n=۷۱ WR=۵۳.۵۲ | | |

⇒ **لیفتِ حاصل ≈ +۶.۵pp** (با ریزشِ nِ ۱۲۵ برابری)

### تفسیرِ ریاضی
«فیلتر کردن» = **انتخابِ زیرمجموعه** روی یک مجموعهٔ ثابتِ نتایج. این یک عملگرِ
**محدود** است، نه معجزه: نمی‌تواند توزیعِ بردوباخت را از نو بسازد، فقط می‌تواند
دُمِ بدِ آن را قطع کند. هرچه پایه به تصادف نزدیک‌تر باشد، اطلاعاتِ قابلِ
استخراجِ کمتری برای این برش وجود دارد.

### پیامدِ عملی (ثابتِ پروژه)
```python
WR_FLOOR_REF    = 61.0   # کفِ G0 (۶۰٪) + ۱pp حاشیه
LIFT_CEILING_PP =  8.0   # ۶.۵pp اندازه‌گیری‌شده + حاشیهٔ خوش‌بینانه
```
**قاعده:** اگر `WR_FLOOR_REF − min(WR_D, WR_H)` پایه **بیش از ۸pp** باشد، آن
پایه با فیلترگذاری **ریاضیاً غیرقابلِ نجات** است ⇒ صرفِ وقتِ محاسباتی روی آن
اتلافِ منابع است.

> این معیار «قانونِ مرگِ ابدی» را از یک شرطِ **ناممکن** به یک شرطِ **قابلِ
> آزمون** تبدیل می‌کند: مرگ زمانی اعلام می‌شود که **هیچ** پایه‌ای در **هیچ**
> تایم‌فریمی داخلِ سقفِ لیفت نباشد.

⚠️ **هشدارِ دامنهٔ اعتبار:** این عدد روی *یک* خانوادهٔ ابزار اندازه‌گیری شده.
باید در نشست‌های بعدی روی منابعِ دیگر بازسنجی و به‌روز شود. تا آن‌زمان یک
**ابرپارامترِ محافظه‌کارانهٔ صرفه‌جوییِ محاسباتی** است، نه یک قانونِ طبیعت.

### دو الگوی تک‌نوا (monotone) که از داده بیرون آمد

**الگوی ۱ — کیفیت با مقیاسِ زمانی صعودی است (طلا، بی‌استثنا):**
```
W1 65.00 > D1 58.06 > H4 54.51 > H1 53.62 > M5 53.19 > M15 50.96 ≈ M30 50.43
```
**الگوی ۲ — کیفیت و N در تضادِ مستقیم‌اند:**
```
W1: q=65.00 maxN=    165        M1: q=30.55 maxN= 44,803
```
همبستگیِ منفیِ تقریباً کامل بین `best_q` و `maxN`.

### علتِ ساختاری (نه صرفاً آماری)
۱. **نسبتِ سیگنال‌به‌هزینه.** اسپرد **ثابت** است (۰.۳۳$/oz طبقِ مشخصاتِ حسابِ
   دمو) ولی دامنهٔ حرکت با ≈√(تایم‌فریم) بزرگ می‌شود. پس هزینهٔ نسبی روی
   تایم‌فریمِ ریز غالب می‌شود. عددِ فاجعه‌بارِ EURUSD-M1 (۳۰.۵۵٪) دقیقاً همین
   است: کندلِ M1 یورو اغلب از اسپرد کوچک‌تر است.
۲. **بازهٔ معناداریِ برگشت‌به‌میانگین.** «برگشت به خطِ میانه» یک گزارهٔ
   ساختاری است؛ روی M1 آنچه شکلِ کانال دیده می‌شود عمدتاً نوسانِ ریزساختاری و
   اثرِ دفترِ سفارش است، نه ساختارِ قیمتی.
۳. **EURUSD به‌طورِ سیستماتیک بدتر از XAUUSD.** نوسانِ نسبیِ یورو کم‌تر است ⇒
   همان اسپردِ ثابت سهمِ بزرگ‌تری از دامنهٔ حرکت را می‌خورد.

## ۴. دو درسِ عملی برای کلِ پروژه

### درسِ ۱ — «مرگ روی یک تایم‌فریم» ≠ «مرگِ ابزار»
روی `XAUUSD-M15` نتیجه قاطعانه **صفر از ۱۲۹۶** بود. اگر همان‌جا حکم می‌دادیم،
منبع DEAD اعلام می‌شد — در حالی که **۵ کارتِ طلا** داخلِ محدودهٔ قابلِ نجات‌اند.
این مصداقِ عینیِ **اشتباهِ رایجِ #۵** است و نشان می‌دهد چرا قانونِ MTF باید
**قبل** از حکم اجرا شود، نه بعد از آن.

### درسِ ۲ — «بیشینه‌سازیِ N» به‌عنوان تابعِ هدف، خطا بود
استدلالِ اولیه: «لبهٔ خامِ بی‌طرف با N نجومی بهترین بسترِ فیلتر است.»
داده این را **رد کرد**: N بالا با کیفیتِ پایهٔ *پایین* هم‌بسته است، و سقفِ
لیفتِ ۶.۵pp اجازهٔ پر کردنِ شکافِ ۱۴pp را نمی‌دهد.
**تابعِ هدفِ صحیح:** «بیشترین N از میانِ پایه‌های *قابلِ نجات*» — یعنی قیدِ
کیفیت **قبل از** رتبه‌بندیِ N اعمال شود.
یادآوری: دروازهٔ G0 فقط `n ≥ ۳۰` می‌خواهد؛ N بالا برای **معناداریِ آماریِ G3**
مفید است، ولی **جانشینِ** کیفیت نیست.

### ⚠️ هشدارِ شکاکانه دربارهٔ W1 (ثبت‌شده پیش از آزمون)
بهترین هندسهٔ W1 **`breakout/long`** است — یعنی **خریدِ شکستِ صعودی روی طلای
هفتگی**. در بازهٔ داده، طلا یک روندِ صعودیِ سکولارِ بزرگ داشته است. پس WR=۶۵٪
می‌تواند صرفاً **بتای بازار** باشد، نه لبهٔ واقعی.
**آزمونِ ابلیشنِ اجباری پیش از هر پذیرشی:** همان هندسه با `side='short'`
سنجیده شود. اگر لانگ کار کند و شورت به‌شدت شکست بخورد، لبه **متقارن نیست** و
باید به‌عنوانِ «قرارگیریِ جهت‌دار» گزارش شود، نه لایهٔ الگویابی.
(این هم‌ارزِ ابلیشنِ اجباریِ زمان است که برای سپرِ اشتباهِ #۱ اجرا می‌کنیم.)
